# Canonical native device owner, stage32

New Android native_vulkan_device service owns the actual Presentation/Vulkan instance, surface, selected physical device, logical device, queue/swapchain and retirement. Configure is backend selection only; it rejects changes while a device is live. Open rejects invalid/non-Vulkan SDL windows, another live owner and undrained native resources, creates the actual Vulkan device, queries actual hardware and attaches native image/buffer/shader contexts. Close runs on the creating SDL owner and rejects registered or borrowed GPU resources/shader/declaration owners before context/device retirement.

R_CreateDevice has a source-scoped native branch: validates the actual window and1x sample policy, calls that real service, stores QueryHardware-derived caps and genuine1x/depth/gpu defaults. D3D pointers remain null; no fake COM object/readiness. Remaining R_InitHardware stages are intact. The diagnostic entry now invokes this canonical function and borrows the resulting presenter, replacing its independently owned device. It destroys material owners before closing the device, then SDL window/video, and resets configuration.
