Authoritative wire protocol is IPv4 numeric address, TCP port7000, two strings per message; each is four-byte network-order uint32 length followed by exactly that many payload bytes. Newlines are ordinary payload bytes. There is no ack/newline framing in this owner. Native send handles partial header/payload writes, signed native socket errors, EINTR/backpressure and MSG_NOSIGNAL. Pair sends hold one connection transmit lock to prevent another sender interleaving type and text.

Nonblocking receive retains partial headers and payloads until the whole current pair is ready. No output is modified on Pending; exact recipient capacity is checked before payload storage/copy, advertised lengths remain uint32 and must leave a terminator byte. Raw zero-length string frames are valid; EOF is never converted into a successful empty string. Reads consume exactly current frame bytes, preserving the next message. Invalid/null storage, malformed oversized lengths and EOF mid-header/body retire connection and fail explicitly. Canonical failure reporting preserves exit255 disconnect policy, after service locks and operation descriptor references retire. Init failure uses actual Com_Error; no success substitute.

Descriptor starts absent (fd=-1 in the connection), zero is valid. Shared operation ownership prevents descriptor reuse while I/O is in flight; shutdown marks closing, clears connected readiness, performs actual SHUT_RDWR, removes current ownership and closes once outstanding references retire. The canonical shutdown also release-clears existing g_MonkeyIsRunning. Connect/send deadlines are five seconds, poll slices at most50ms to observe cancellation even when shutdown during a pending connect yields ENOTCONN. Shutdown cancels rather than indefinitely draining a peer that never closes. No service lock crosses logging/error/engine callbacks. Start/stop publication must remain controlled by the engine startup owner; operations are safe against concurrent cancellation but callers may not race independent engine-level Monkey_Start lifecycles.
