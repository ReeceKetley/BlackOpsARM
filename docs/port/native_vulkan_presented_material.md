2026-10-14. Native replacement goal incomplete. Native buffer/texture/pipeline ownership now drives an actual displayed T5 shader material in the EngineActivity APK. The displayed image is a previously captured room fixture, not a live scene generated by the native backend. No game FPS or completion claim.

## Implementation

`src/gfx_vulkan/resources.{h,cpp}` provides bounds-checked persistent mapped Buffer and optimal-tiled RGBA8 Texture2D owners. Required memory type bits/properties are checked; coherent/device-local memory is preferred where compatible. Noncoherent writes flush atom-aligned mapped memory ranges. Caller controls fence retirement before reuse/destruction. Texture initial upload records outside a render pass and transitions transfer-write to sampled-read; its staging buffer survives GPU use. Formats/mips/cubes/streaming/suballocation beyond this initial provider still require implementation.

Presentation accepts a prepare callback outside the render pass, after the frame slot fence retires. `native_vulkan_material_preview.cpp` uses two independent mapped vertex/uniform buffers and descriptor pools, writes/resetting only the retired slot, and draws the actual semantically linked T5 fullscreen VS and colour PS through GraphicsProgram. Texture upload occurs once per preview lifetime. Pipeline recreation follows presentation generation changes; resources remain owned until device retirement. This integration is the basis for adapting actual engine resource providers, not an independent engine implementation.

Native projection now accounts for swapchain surface transform. The tablet reports ROTATE_90 (2), and unrotated rendering appeared90degrees counterclockwise. `Presentation::PreRotateProjection` rotates clip rows using the actual reported transform; corrected screenshot is upright. Other transform mappings are implemented but not individually device-tested. Mirrored transforms change winding; general scene culling adaptation remains pending. Full engine camera/viewport conventions still need integration.
